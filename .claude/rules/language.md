# Language

- Conversation, code, comments, identifiers, commit messages and PR descriptions are in **English**.
- The **user interface is in Portuguese (pt-BR)**: labels, buttons, messages, validation errors shown to users, page titles.
- API error messages that reach the UI are returned in Portuguese; internal logs stay in English.
- Files in `tasks/` are written in Portuguese. Keep them in Portuguese when editing; do not translate them.
- Domain terms keep their agreed names (see `tasks/00-visao-geral.md`): the person identifier is **matrícula** (`registrationNumber`); never use "RA". Enrolling in classes is **inscrição**, not "matrícula".
